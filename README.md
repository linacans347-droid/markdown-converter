# Markdown Converter 📝

Удобный и быстрый веб-инструмент для преобразования разметки Markdown в готовый HTML-код в реальном времени. Проект создан в рамках практического обучения frontend-разработке.

## 🚀 Демонстрация
👉 [Посмотреть проект в действии](https://github.io)

## 🛠 Технологический стек
* **JavaScript (ES6+)** — логика обработки текста и управление DOM-деревом.
* **HTML5 / CSS3** — семантическая структура и адаптивный, отзывчивый интерфейс.
* **Marked.js** — библиотека для парсинга и безопасной конвертации разметки.

## 💡 Реализованный функционал
* **Режим Live Preview:** HTML-результат обновляется мгновенно прямо во время ввода Markdown-текста.
* **Адаптивный дизайн:** Интерфейс корректно отображается как на экранах мониторов, так и на мобильных устройствах.
* **Очистка данных:** Безопасный вывод откомпилированного HTML без уязвимостей.

## 🔧 Как запустить проект локально
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл `index.html` в любом современном браузере
